# 🤖 Python Chatbot

A simple **Python-based interactive chatbot** built to practice core Python programming concepts.

The chatbot can greet users, display the current date and time, tell random jokes, perform basic calculations, and provide an interactive help menu.

## ✨ Features

* 👋 Interactive greetings
* 🕐 Displays current time
* 📅 Displays current date
* 😂 Random jokes
* 🧮 Basic calculator
* 📋 Interactive help menu
* 🤖 Simple conversational responses
* 🚪 Exit using `bye` or `exit`

## 🛠️ Technologies Used

* **Python**
* `datetime` module
* `random` module
* User input
* Conditional statements
* Loops
* Functions
* Exception handling

## 🚀 How to Run

### 1. Clone the repository

```bash
git clone https://github.com/Umer00/Chatbot.git
```

### 2. Open the project folder

```bash
cd Chatbot
```

### 3. Run the chatbot

```bash
python Chatbot.py
```
